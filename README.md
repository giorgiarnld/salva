# Reading Progress Tracker

Reading Progress Tracker is a lightweight Python application for managing your personal reading library and tracking reading progress.

## Features

- Add books
- Update reading progress
- Reading statistics
- Reading sessions
- JSON storage
- CSV export

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

## Menu

```
1. Add Book
2. Update Progress
3. Library
4. Statistics
5. Export
6. Exit
```
